# Canceled-navigation residue proof

## Runtime sequence

A local Chromium page clicks an ordinary link whose response is an attachment.
The navigation reports failure without replacing the document. The live page
starts `/api/probe`, performs `history.pushState`, then receives HTTP 503 and
renders its fallback state.

`before-residue.json` uses `trackDataResidue` from main commit
`12d71f0954e44d1401136d5fc9c37d8daa7d78b4`: no named failure and no unacknowledged
endpoint. `after-residue.json` uses this branch: the armed residue audit contains
`dashboard·/api/probe`, reason `HTTP 503`, as unacknowledged. `fallback.png` shows
the actual page after this sequence. The same DOM fallback occurred before the
fix; the correction is failure attribution, not a change to the fixture's UI.

Reproduce the automated regression from the repository root:

```sh
npm run build
npx playwright test test/cancelled-navigation-probe.e2e.spec.ts --workers=1
```

The browser test waits for the actual navigation failure and download event,
asserts that the page URL survives, holds the API response until after pushState,
and asserts the named failure in the armed gate. It failed on unfixed main
(expected `dashboard·/api/probe`, received `[]`) and passes on this branch.

## Generated reports and limits

The before/after report examples were generated by this branch's report engine
from each actual watcher's residue result. Their maps deliberately contain empty
element/style/state collections: these examples isolate the failed-data-request
path, not a full capture or certification of an application. `determinism:
self-checked` is controlled fixture ledger metadata, not a claim that a consumer
capture was self-checked. No expected surface registry, inventory or product-state
identity is asserted.

All warnings are retained in the report and screenshot: legacy product-state
identity is unproven, coverage/confidence are unasserted, inventory is not checked,
and content/structure is not evaluated. The no-style-change line describes only
the supplied empty computed-style maps; it does not negate the failed API line
or certify the fixture. `after-report.png` shows the generated report with Evidence
expanded. The report HTML/Markdown/JSON and input maps are committed for inspection.

The fix preserves true cross-document handoffs and already-recorded failures,
including self-check folding. It clears completed canceled navigations; it does
not claim to solve every overlap between a still-pending navigation and pushState.
