StyleProof integrity repair

CERTIFICATION_FAILED stays unapprovable. Each reason names what broke, what to fix, and how to verify.

Reviewer approval cannot clear these states. Repair the evidence, then re-run.

connector-partial — Map connector returned a partial bundle

  • What broke: The map-store or evidence connector restored only some of the expected surfaces. Certification cannot compare a partial restore as if it were a complete pair.
  • What to fix: Restore or recapture the missing surfaces and republish the bundle. Do not tick visual approval.
  • How to verify: Re-run styleproof-diff or the Action. The connector receipt must read complete.

duplicate-id — Duplicate identity in a style map

  • What broke: A style map contains a duplicate JSON key or a duplicate inventory identity. JSON.parse would keep only the last value.
  • What to fix: Give each element or affordance a unique key, then recapture.
  • How to verify: Re-run styleproof-diff or the Action. The report must no longer name duplicate-id.

integrity-mismatch — Claimed evidence digest does not match the bytes

  • What broke: A source SHA or content digest does not match the bytes on disk.
  • What to fix: Restore or recapture from the exact claimed SHA. Do not reuse a map that failed digest verification.
  • How to verify: Re-run styleproof-diff or the Action. Claimed and actual digests must match.
