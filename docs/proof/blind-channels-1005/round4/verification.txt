Design and changes:
- captureVisualChannels stays opt-in/off by default, with no map schema bump, dependency change or default verdict expansion. Existing v1 name/hash references and shared bodies remain.
- A single flat document animation index, keyed by effect.target and pseudoElement, replaces Element.getAnimations calls. Synchronous model snapshots precede protocol work, so finishing animations cannot change the model's liveness between reads. The full author-root traversal is cached once per capture; later sessions initialise only a depth-0 document root.
- No pause/play/currentTime mutation is used. The initial motion unfreeze and model read share one synchronous evaluation; default-off still calls the original unfreeze reader. Later protocol calls carry the captured models forward.
- var() consumers stay unknown for animated custom-property inputs on the element or ancestors. Matched-rule declarations are inspected even for opaque-sheet inputs. Missing/ambiguous input declarations also hold the consumer unknown. Non-CSS animations, including Web Animations/transitions, have unverified declarations and conservatively hold variable consumers unknown.
- Same-offset frames form dependency edges only for shared computed properties; a heap selects a canonical topological order. Disjoint groups commute, shared-property groups preserve relative engine order. Property keys and equivalent easing remain normalised. No CSSOM declaration merging replaces engine values.
- Identical CSSOM duplicate definitions no longer cause unknown. Loaded opaque sheets can be overridden only by engine/source agreement; CDP loaded-sheet headers distinguish a failed sheet (which Chromium may expose through a SecurityError-throwing CSSStyleSheet) from a loaded cross-origin sheet. Missing, untraversed, mismatched, conditional/ambiguous or unavailable evidence stays unknown.
